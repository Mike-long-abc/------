# 串口日志与指令工具

这是一个 Windows 串口调试工具，用于实时查看设备日志、保存 TXT 日志、搜索关键日志，以及发送和管理常用工厂指令。

## 文件说明

- `serial_log_recorder.py`：工具主程序。
- `serial_commands.json`：常用指令及简短说明。
- `启动串口日志保存工具.bat`：Windows 快速启动脚本。
- `串口日志\`：默认日志保存目录。

## 运行环境

- Windows 10/11
- Python 3.10 或更高版本
- `pyserial`
- Tkinter（Windows 官方 Python 通常已自带）

安装串口依赖：

```powershell
python -m pip install pyserial
```

## 启动方法

双击：

```text
启动串口日志保存工具.bat
```

或在 PowerShell 中运行：

```powershell
cd "E:\LEIDA_PROCESS\ESP32第二代雷达检测仪器\串口日志软件"
python .\serial_log_recorder.py
```

## 基本使用流程

1. 连接设备，点击“刷新”。
2. 选择对应的 COM 口，通常使用 `115200` 波特率。
3. 点击“打开串口”，实时日志将显示在黑色窗口中。
4. 如需保存，设置保存目录和文件前缀，再点击“开始保存”。
5. 点击“结束保存”只会停止写文件，串口仍保持打开。
6. 点击“关闭串口”才会释放 COM 口。

> 同一个 COM 口不能同时被 SSCOM、MobaXterm、`idf.py monitor` 或其他串口软件占用。

## 日志保存

- 保存文件格式为 `.txt`。
- 使用 UTF-8 BOM 编码，Windows 记事本可正常识别中文。
- 文件名格式：`前缀-COM口-年月日-时分秒.txt`。
- 窗口会显示 ANSI 颜色，保存到 TXT 时会自动移除颜色控制码。
- 用户上翻日志后，新日志不会强制拉回底部；滚回底部后恢复自动跟随。

## 查找日志

1. 在顶部“查找”输入框输入关键字，例如 `OTA END`、`webrtc`、`Failed` 或 `mqtt`。
2. 所有匹配项会被标记，当前匹配项会以橙色高亮。
3. 点击“上一个”或“下一个”循环查找。
4. 回车查找下一个，`Shift + 回车` 查找上一个。
5. 右侧显示当前位置和总匹配数，例如 `2/15`。

查找默认不区分英文大小写，不会修改或过滤保存的日志。

## 发送指令

1. 打开串口。
2. 在底部指令输入框填写命令。
3. 点击“发送”或按回车。

工具发送指令时会自动追加 `CRLF` (`\r\n`)。已发送的命令会在显示窗口中以“[发送]”标记；正在保存时，也会写入 TXT 日志。

## 常用指令管理

- 点击常用指令按钮：只填入指令输入框，不会立即发送。
- 可在输入框中继续修改参数，确认后手动发送。
- “新增常用”：将输入框内容保存为新按钮。
- “修改选中”：修改已点选指令的名称、命令和说明。
- “删除选中”：删除已点选的常用指令。
- 修改结果保存在 `serial_commands.json`。

## 常见问题

### 串口列表是空的

1. 确认 USB 线支持数据传输。
2. 在 Windows 设备管理器中检查“端口 (COM 和 LPT)”。
3. 安装对应的 CH340、CP210x 或设备驱动。
4. 拔插设备后再点击“刷新”。

### 提示串口被占用或拒绝访问

关闭 SSCOM、MobaXterm、ESP-IDF monitor 和其他正在使用该 COM 口的软件，然后重新打开串口。

### 看不到日志

- 检查 COM 口和波特率是否正确。
- 确认设备已上电并且确实从该串口输出。
- 关闭串口后重新打开，或重启设备观察启动日志。

### 无法启动，提示缺少 `serial`

```powershell
python -m pip install pyserial
```

### 中文显示异常

新版工具使用增量 UTF-8 解码。如设备输出本身不是 UTF-8，仍可能出现乱码，需要先确认固件的日志编码。

## 注意事项

- 请勿在真实产品设备上随意发送写入配置、清空 NVS、重启或 OTA 相关指令。
- 含密码、MQTT 凭据、License 或 Token 的日志不应公开分享。
- 进行 OTA、上传、通话等测试时，建议先点击“开始保存”，并在文件前缀中注明测试项目。
